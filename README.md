# Валютный Конвертер

Этот проект — **конвертер валют** с использованием **React**, **TypeScript** и **Vite**.

## Стек технологий

- **React** 19
- **TypeScript** 5.7.2
- **Vite** 6.2.0
- **Tailwind CSS** 4.1.3
- **ESLint** для линтинга кода
- **Центральный банк РФ API** для получения курсов валют

## Развертывание проекта

### 1. Клонирование репозитория

Для начала, клонируйте репозиторий:

```bash
 git clone https://github.com/Roman17082000/valuta-hub.git
 cd valuta-hub
```

### 2. Установка зависимостей
```bash
 npm install
```

### 3. Запуск проекта в режиме разработки
```bash
 npm run dev
```

### 4. Построение проекта

Для того чтобы собрать проект для продакшн-режима, выполните:

```bash
 npm run build
```

Структура проекта

	•	src/ - Основная папка с исходным кодом
	•	components/ - Компоненты React
	•	lib/ - Логика работы с API и вспомогательные функции
	•	types/ - Типы TypeScript
	•	mockRates.ts - Моковые данные для курсов валют (используются в случае отсутствия подключения к API)

О проекте 

	•	В проекте используется API ЦБ РФ для получения актуальных данных о курсах валют. Если API недоступен, проект будет использовать локальные данные (mockRates).
	•	Подключение к API ЦБ РФ осуществляется через метод fetchRates.
	•	Взаимодействие с пользователем происходит через удобный интерфейс, который поддерживает выбор валюты, ввод суммы и выбор даты.
